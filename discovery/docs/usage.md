# Planned usage

Create one workspace per customer or independent context. Paste original text in the left editor and review sanitized output on the right. Structured sensitive values are replaced automatically. Ambiguous terms appear in the pending list, where you choose ALWAYS or NEVER once.

For ALWAYS, confirm the suggested prefix or choose an existing placeholder. When a similar term appears, decide whether it is the same entity. If multiple originals share a placeholder, select the principal original used for restoration.

Paste an AI response containing placeholders into the right editor to restore canonical originals on the left. Restored output is sensitive and must not be sent back to a public LLM.

Use the Terms screen to search, add, edit, merge, split, delete, or change principal values. Closing the app preserves dictionaries and decisions but not editor text.
